Drop a HAR file. See how much was a repeat.

Everything runs in this browser tab with its own SHA-256. The file is never uploaded. HAR files can contain credentials, so treat them like one.

Drop your .har file here or

Chrome and Edge: DevTools → Network → right-click → Save all as HAR with content. Firefox: Network → gear → Save All As HAR. Safari: Network → Export.

How to read it

  • Repeated bytes are chunks whose fingerprint was already seen from the same host in this file. Repeats are never counted across hosts.
  • Wire bytes come from the HAR's own size fields and are labelled observed, estimated or unavailable. Compression is nonlinear, so repeated decoded bytes do not equal repeated transfer bytes.
  • Dollars appear only for providers that bill by bytes, and only after you enter and confirm your own contract rate. Everywhere else you get a percentage and nothing more.
